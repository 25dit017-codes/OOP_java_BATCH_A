# Java OOP Practicals 1–5 — Complete Code Collection

Course: Object Oriented Programming (CEUE203)  
Environment: JDK 17+

This archive is organized by practical, then by `Part_A` (practice programs) and `Part_B` (MiniBank project).

## Contents
- Practical 1: Vending Machine, Toll Booth, RPSLS, MiniBank menu
- Practical 2: Thermostat, Cinema Show, Parking Lot, Customer and Account model/demo
- Practical 3: Point equality, Card duplicate check, Fraction reduction, MiniBank object methods/address/cloning demo
- Practical 4: Password checker, chat log filter, template filler, MiniBank validators/command parser/statement formatter
- Practical 5: Shape polymorphism, Payroll, media late-fee example, abstract MiniBank Account and account subclasses

Advanced and supplementary exercises are included where practical. Files are separated into folders to avoid conflicting class names such as `Driver`.

## Compile and run
Open a terminal in the folder containing a Java file, then run:

```bash
javac FileName.java
java ClassName
```

For a program that uses several source files, compile them together, for example:

```bash
javac *.java
java Driver
```

Use JDK 17 or newer. Some programs intentionally use records, switch expressions, and pattern matching for `instanceof`.

## Important notes
- These are separate practical exercises, not one combined application. Compile/run each folder independently.
- Part B code evolves from practical to practical. Later MiniBank versions extend or replace earlier model classes; keep each practical's folder separate.
- Sample output is illustrative when random values or user input affect results.
